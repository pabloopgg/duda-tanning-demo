# DUDA Tanning: demonstração

Agenda online e painel de gestão para espaços de bronzeamento, num arquivo só, em **modo de teste**:
os dados ficam no navegador de quem abre e começam zerados.

**Abrir:** https://pabloopgg.github.io/duda-tanning-demo/

- No topo, escolha **Cliente** (o site que o cliente usa) ou **Painel do gestor**.
- No painel, qualquer e-mail e uma senha de 4 letras ou mais entram.
- Comece pelo painel: cadastre os espaços e os pacotes em Serviços. Depois agende pelo lado do cliente.

Este repositório só tem a demonstração (gerada com `npm run build:demo`). O código do sistema fica em outro repositório, privado.
